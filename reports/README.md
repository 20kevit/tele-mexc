# Historical Reports Archive

All files under `reports/` are dated investigation records, not current
operational documentation. They preserve evidence and findings from the
branches and database snapshots named inside each report.

Current behavior is defined by the canonical docs:

- Trading: `../docs/trading.md`
- Operations: `../docs/operations.md`
- Architecture: `../docs/architecture.md`
- Data model: `../docs/data-model.md`
- Live verification: `../docs/LIVE_VERIFICATION.md`

Some reports contain historical account/trade identifiers. They are retained
for audit traceability and must not be used as configuration guidance or copied
into new documentation. Do not infer current defaults, modes, or command
availability from these reports.
