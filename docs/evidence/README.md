# Historical Evidence Dossiers

Files under `docs/evidence/` are dated forensic/research records. They are not
current operating instructions. Current behavior is documented in
`../trading.md`, `../operations.md`, and `../data-model.md`.

These dossiers may contain historical order/trade identifiers from disposable
test databases or past investigations. Do not reuse them as configuration,
examples, or proof of current live verification.
